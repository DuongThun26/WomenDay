HƯỚNG DẪN BỔ SUNG FILE NHẠC TÙY CHỌN:

Mặc định, ứng dụng đã tích hợp sẵn bộ phát synthesizer Web Audio API tạo giai điệu Lofi Acoustic Piano hoàng hôn êm dịu mà không cần file ngoài.

Nếu bạn muốn sử dụng bài hát/bản nhạc mp3 riêng của bạn:
1. Đặt file âm thanh định dạng MP3 vào thư mục này với tên:
   sunset-melody.mp3
   (Đường dẫn đầy đủ: public/assets/audio/sunset-melody.mp3)
2. Khi đó website sẽ ưu tiên phát file nhạc này kèm vòng lặp loop mượt mà.
